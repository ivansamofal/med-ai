Cross-cutting (Phase 6–7):
  - Evaluation: golden Q&A set → citation-presence + faithfulness checks (`make eval`)
  - Red-flag test cases → must trigger escalate_to_oncall, never a plain answer
  - Observability: per-request token/cost tracking, latency tracing
  - PHI-safe structured logging (redaction) across every service
  - Full audit log: every AI-authored write (draft, approval action, booked appointment)

Optional (Phase 8):
  - Chat agent split into a supervisor pattern:
      intake_agent -> retrieval_agent -> scheduling_agent -> compliance_agent
    each a LangGraph node, once the single-agent version is proven solid.

────────────────────────────────────────────────────────────────
Division of labor (why each tool is used where):
  LlamaIndex   -> knowledge base ingestion + retrieval only
  LangChain    -> single-shot retrieve -> prompt -> generate (no branching/state)
  LangGraph    -> anything stateful/branching: approval workflow, tool-calling agent
